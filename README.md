# Inovar Elevada

Site institucional da Inovar Elevada Materiais de Construção, em Vacaria/RS.

A versão atual usa uma arquitetura separada em `index.html`, `styles.css` e `app.js`, com assets próprios para logo e fachada, navegação responsiva, consulta por WhatsApp, setores, avaliações, Instagram, Google Maps/Waze e consulta de disponibilidade de entrega.

Horário de atendimento: segunda a sexta-feira, das 8h às 18h30; sábado, das 8h às 18h.
