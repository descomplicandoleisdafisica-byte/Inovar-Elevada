# Inovar Elevada

Site institucional da Inovar Elevada Materiais de Construção, em Vacaria/RS.

A versão atual foi reconstruída com foco em:
- navegação responsiva;
- busca com consulta via WhatsApp;
- setores da loja;
- avaliações;
- Instagram;
- Google Maps/Waze;
- consulta de disponibilidade de entrega;
- estrutura separada em `index.html`, `styles.css` e `app.js`.
